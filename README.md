# AI桌面助手

Windows 桌面宠物，支持二维角色、文字聊天、本机记忆和 Codex / WorkBuddy 任务提醒。

当前版本 **1.23.0**。右键菜单保留设置、隐藏和退出；日常双击角色打开聊天。程序文件仍叫 `StarPet.exe`，便于兼容旧版安装。

## 功能

- 二维角色：内置形象、自定义图片和角色包；可把一只猫与对应的成年人物配成同一角色。闲时显示猫，聊天时显示人物。
- 动作：播放角色包中的透明动画，支持摸头、点击和拖动；静态图片使用静态显示。
- 文字聊天：可选择 Codex 官方 CLI、本机 Ollama 兼容服务或独立 CodeBuddy CLI；模型按连接方式分别保存。
- 记忆：查看、编辑和删除当前角色的记录；不同角色分别保存。内容在发送时按开关附带，不是模型训练。
- 任务提醒：只读监听本机客户端的状态变化；等待、错误和本轮完成优先显示。
- 小场景：房子、树和装饰显示在角色后方，随角色移动。
- 专注计时：本机运行，可暂停和恢复，到点后由用户选择下一步。
- 回复朗读：使用 Windows 已安装的声音，默认不自动朗读。

没有语音输入、实时三维模型或内置云端生图。图片重绘可连接已经运行的本机 ComfyUI，生成结果须预览后再创建角色。换装和房屋生成的设计试作未作为正式功能发布。

## 运行

从 GitHub Releases 下载 Windows 完整包，解压后运行 `StarPet.exe`。`_internal` 文件夹需要与 EXE 放在一起。

首次使用可先选择角色。双击打开聊天，在设置中选择聊天连接和模型；缺少服务或未登录时会显示原因。

自定义形象支持 PNG、JPEG、WebP、BMP、TIFF 和 GIF。动态或多页图片通过“从图片创建”入口时只取第一帧；完整动作使用角色包导入。导入不会自动替换当前角色。

## 客户端接入

**任务提醒与聊天连接分别选择。**

Codex 的任务提醒增量读取本机会话日志。WorkBuddy 的任务提醒只读检查本机状态库；国内版工作、结束和错误变化已有验证，审批状态及海外版本的覆盖有限，以原客户端为准。

当前版本不安装 Hook，不修改 Codex 或 WorkBuddy 的客户端配置。设置中的“清理旧版助手接入”仅用于移除旧版本留下的本助手条目，须用户主动点击；其他配置不受影响。

Codex 聊天由用户安装的官方程序处理登录并发送独立文字请求。CodeBuddy 使用助手专用配置，需要单独完成官方登录；其登录和模型权限以当前账号实测为准。本机模型需要已启动的回环服务。程序不会把其他客户端的完整聊天自动导入助手记忆。

## 数据

设置、聊天、角色和记忆位于：

```text
%LOCALAPPDATA%/SATLOOT/StarPet
```

升级保留这个目录。分享问题报告前检查个人内容；不要公开该目录、运行令牌或客户端认证文件。

角色包只带形象、动作与角色设定，不带聊天、记忆或账号信息。模型权重、云服务密钥和用户制作目录不包含在开源仓库中。

## 从源码运行

建议使用 Windows 10 / 11、Python 3.13。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

本机重绘、去背景及本地模型运行是独立工具，所需服务和权重不会自动下载。制作说明见 [随包 Skill](skill/ai-desktop-assistant/SKILL.md) 与 [二维图片制作](docs/2d-generation.md)。

## 检查和构建

自动检查使用独立数据目录。图形检查使用 Qt offscreen 或经过验证的独立 Windows 桌面，禁止回退到用户桌面、切桌面或发送系统输入。

```powershell
python scripts/test_release.py
python scripts/build.py --output-dir release/staging-1.23.0
```

检查结果分别记录单元测试、离屏界面、原生窗口和真实服务。默认检查不会调用模型账号、录音或有声播放。
