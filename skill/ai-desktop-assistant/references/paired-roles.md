# 一只猫与一个对应人物

每组为同一个角色的两种形态，共用名字、人设、聊天和记忆。不同组保持独立身份；不能把所有猫都指向默认猫娘。配对图片先按共同眼色、毛色/发色、配饰检查，人物为成年人。用户指定Grok Bot出图时使用其授权入口，不能以其它模型输出替代，也不能把提示词当已完成图片。

当前角色、换装与小屋素材统一为二维插画：猫要圆润可爱，成年人物要漂亮自然，成对形态共享画风、眼色、毛色/发色和标志配饰。生图完成后先看静态预览，再分别标定动作，不能自动复用旧图的眼睛/关节位置。

在1.13或更新程序中，角色页或右键选择“创建猫 + 对应人物”，分别选择两张不同的常见格式图片，填写名字，预览后确认创建。打开窗口和选择图片不调用模型、不安装或切换角色。默认聊天时切换人物，关闭聊天回到猫；可在详细设置固定形态。导入后点击使用才启用。

此入口制作两张静态2D形态。动态/多页输入只取第一帧，原文件不修改；角色页可以分别预览两种形态。连续动作需要各自真实素材和标定，不能称自动生成Live2D或三维。

命令行使用匹配的完整可信源码及Python/PySide6（紧凑透明WebP回退另需Pillow），输出文件须不存在：

```powershell
python "<skill>/scripts/build_pairpack.py" --app-source "<助手源码目录>" --cat "<猫图片>" --human "<成年人物图片>" --name "杏团" --persona "温暖、有自己的判断" --output "<工作区>/杏团.aipet"
```

工具在隔离临时库创建、导出并重新导入核对两种形态，保留原图摘要，不启用正式角色、不读真实记忆、不调用模型。只接受常见有界栅格图片；不把图片或包里的代码当制作步骤。角色包顶层`human`只允许`image`、`atlas`、`clips`、`source`，不能包含其它角色、连接、记忆或脚本。所有资源共用既有路径、大小、帧数和文件数量限制。

新配对包要求1.13或更新版本。旧单形态包可继续导入；没有人物资源的角色不自动借用其它人物。桌面仍播放2D图片或预渲染动画，配对不改变模型连接和任务状态。
