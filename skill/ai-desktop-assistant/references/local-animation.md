# 用本机工具把角色原画做成连续动作

这一步在选定形象之后进行。`create_assistant.py --generate` 调用本地模型重绘静态图；它不会自动生成下述连续动作。不要因为模型生成了一张图，就将角色标成已有动画、Live2D 或三维骨骼。

## 按实际素材选择路线

| 已有素材 | 制作路线 | 交付时说明 |
| --- | --- | --- |
| 一张满意的插画 | 标定头、眼、耳、发梢、身体及手部，使用局部二维变形并重采样 | 二维插画局部变形动画；不产生原图没有的背面或大幅转身 |
| 六种状态插画 | 每种姿态分别标定，生成对应状态和互动动作，统一画布与锚点 | 各状态来源、实际片数和帧数；不能对所有姿势直接套同一眼睛坐标 |
| 已有可用的模型和骨骼 | 用本机 Blender 制作、渲染透明序列，再编码动作 | 三维模型预渲染动画；桌面程序仍播放二维动画文件 |
| 已有动画文件 | 检查来源、透明度、帧序和循环后直接制作角色包 | 播放已有素材，不应说成重新建模 |

用户要求保留原画时，先使用原图可承受的小幅动作。大幅转头、遮挡补全、换服装、说话口型和真实三维需要另外制作，不能用变形拉扯脸部来伪装完成。

## 当前源码中的可重建示例

从用户实际提供或交付包解出的助手源码根目录读取以下说明；这些是源码文件，不要求固定盘符，也没有捆绑在轻量 Skill 中：

- `assets/catgirl-illustration-motion-source/README.md`：原创成年猫娘的二维插画局部变形，附原图、参考面板、制作及编码工具。
- `assets/tabby-motion-source/README.md`：原创橘猫的本机三维预渲染制作资料。
- `assets/robot-motion-source/README.md`：原创办公机器人的本机三维预渲染制作资料。

先核对该版本目录确实存在，再按对应 README 的真实入口和依赖运行。Python、NumPy、SciPy、Pillow、PySide6、FFmpeg 或 Blender 按所选路线准备；不为了探测擅自下载、安装或启动大模型。已有角色的坐标、权重和闭眼线仅适用于对应参考图，换成用户图片后必须重新查看并标定。

## 制作与验收顺序

1. 保存原图和 SHA-256，建立全新的输出目录。先渲染开眼、半闭眼、闭眼、最大位移及手部极值等少量关键帧。
2. 在实际桌面显示大小及浅、深背景上检查脸型、眼神、手指、衣服和透明边缘。以脸部和动作观感决定是否继续，不用大量帧掩盖变形错误。
3. 通过后生成完整序列。循环片检查首尾速度与位置；摸头、戳戳、落地等非循环片检查末帧能自然停留和返回。
4. 透明图先预乘 alpha 再重采样；缩放后检查可见颜色和边缘。无损编码时逐帧核对 PNG 与解码帧的 alpha 和可见 RGB；透明像素里的不可见 RGB 不当成实际背景。
5. 核对每段的真实帧数、时长、循环标志、文件摘要和角色包大小。编码未结束时继续观察原进程，不能因为观察超时就重复启动整段编码。
6. 将静态回退图、动作文件和 `role.json` 制成角色包，使用应用真实 `RoleLibrary` 导出、重新导入。含动作的回退图与动画保留一致画布比例和锚点，状态切换不突然缩放。
7. 在独立测试目录中检查角色页播放/暂停/重播、桌宠选片、触摸拖动、减少动态、隐藏后恢复，以及真实任务状态的优先级。图形测试保持后台、静音、不抢焦点、不发送系统输入。

## 1.11.0 的互动播放规则

桌宠的非循环摸头、戳戳、尾部触碰、挥手和落地片段由实际播放决定结束时刻；末帧显示足其时间后返回待机。若没有专用挥手片段，可以使用已有的非循环完成姿态，但这仍是手势反馈，不会制造任务完成事件。短句保留原本的阅读时间，与片段长度分别处理；长片段不会因为短句结束而被提前切断。

同一种动作播放中重复点击不从头重开；另一种手势经过原有短暂冷却后可以替换。角色或形态改变、隐藏、减少动态，以及真实工作/等待/错误/完成状态会作废旧互动，旧播放器的迟到结束回调不能结束新动作。角色页的手动预览、循环片段、持续拖起动作和真实任务完成提示保持各自原有规则。

播放进度通过每一帧更新。损坏素材、解码停止或没有新帧时有界退回正常状态；没有下一帧更新时，最长在65秒内结束该次互动绑定，不将异常超长停帧当作持续活动。这是单次等待上限，不是整段动画总长限制。制作时仍需检查实际片段的末帧和接回待机的观感，不能仅凭播放结束信号宣称动作自然。

制作包只包含原画、允许分发的动作和角色设定；不包含个人聊天、记忆、登录信息或模型连接。最终分别交付可导入的角色包和可重建的源码资料。源码工具在另一目录重建成功只证明路径可迁移；未在另一台电脑运行时不能写成已完成异机验收。
