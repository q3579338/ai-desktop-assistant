# 成长档案第一版（1.17.0）

打开聊天窗口的“成长”页。选择表达偏好，开启并保存；可添加明确确认的偏好/经历，选中后删除，或恢复初始档案。还需在记忆设置中启用长期记忆才会带入聊天请求。关闭成长仅停止后续请求带入，已有聊天和正在生成的请求不会被追溯删除。

档案保存在助手自己的 `growth-profiles/local/<role>.json`。同角色猫/人物共用，角色之间分开。此版本使用当前本机用户的资料空间，不提供同一Windows账户内的多用户登录切换。底层支持独立user命名空间，不能把这项测试支持说成完整账号/访问控制系统已经做完。

表达偏好为原角色风格、简短、详细、温和。记录最多30条，每条300字。仅显式输入，不自动读取客户端历史或把推断当事实。写盘失败保留旧档案和输入。恢复初始需要确认，不删除旧聊天或原有记忆。

读取发生在每次构建聊天上下文时；这是请求侧偏好，不是模型参数训练。模型是否遵从仍需用所选服务实测；没有宣称已完成多人真实模型风格评测。成长不改变工具权限、账号、生图预算或任务状态。当前请求界面的长期记忆条数沿用原记忆页统计，成长档案在独立页查看，不混算为自动提取事实。

本次没有安装Mem0/Letta/AIRI，没有调用模型、下载权重或注册外部服务。后续可以在保留档案格式与用户控制的前提下验证可替换记忆检索。公共程序包不含growth-profiles目录。
