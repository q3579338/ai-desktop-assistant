# 指定聊天模型（1.17.1）

聊天页点“选择聊天模型”，或右键 → 全部设置 → 聊天连接/模型。选择接入方式，在“指定模型（可输入完整模型名）”中输入该账号支持的真实模型ID，然后保存。Codex、WorkBuddy/CodeBuddy、本机服务各自保存模型名，不修改客户端全局设置。

留空表示不传模型参数，交由官方CLI决定；不能保证继承桌面客户端当前模型。清空按钮只改草稿，保存才生效。正在回复时不能切换已保存配置，避免把本轮回复归到另一个模型。聊天页“指定”是请求值，不是服务端实际型号回报。

Codex指定值通过 `-m` 传给官方CLI；CodeBuddy通过 `--model` 传入。本地服务使用其请求体model字段。用户须有对应模型权限。无权限/不存在/网络失败按服务返回错误处理；助手不会在收到明确模型失败后自动重试别的型号，但不能保证官方服务内部没有别名或路由。

“检测连接”对两个官方CLI主要验证程序能力或登录，不证明指定模型可用；真实请求成功才能进一步验证。没有自动调用模型、购买额度或下载模型来填下拉列表。当前仍没有对每轮实际服务端模型的完整展示。
