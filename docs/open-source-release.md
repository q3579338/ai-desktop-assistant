# 开源源码快照

公开版本使用 MIT 许可证，项目名称为 AI桌面助手，兼容程序名为 StarPet。源码快照包含纯二维桌面程序、角色制作工具、便携 Skill、自动化测试与必要的运行图片。聊天账号仍由用户选择的官方程序管理；本项目不提供账号、模型额度或模型权重。

公开快照通过 `scripts/export_open_source.py` 的明确清单建立，不复制原工作区的 Git 历史。导出命令本身不登录 GitHub、不创建仓库，也不上传文件。先不带 `--write` 检查清单，再指定新的目录写入：

```powershell
python scripts/export_open_source.py --output release/open-source-snapshot
python scripts/export_open_source.py --output release/open-source-snapshot --write
```

目录已经存在时会停止，避免覆盖之前审阅过的快照。发布操作应在这个新目录建立全新 Git 仓库，再由发布负责人推送到实际确定的 GitHub 仓库。工作目录原有历史、远程设置和其它项目不受影响。

快照排除个人设置、聊天和记忆、登录与运行令牌、创作原图及任务、后台验证记录、依赖缓存、已构建程序、模型权重，以及已取消的实时三维试作。`SOURCE_MANIFEST.json` 记录具体文件、字节数和 SHA-256；它不包含用户资料或本机绝对路径。导出前逐个检查已知秘密格式，并拒绝符号链接及异常大文件；这项检查不应被宣传为完整安全证明。

运行素材的来源分别保留在角色目录的 `character.json` 与 `concept.json`。猫娘图集的 SHA-256 与本项目原始图集记录一致；小猫和机器人图集的 SHA-256 与本项目保存的原始概念图记录一致。对应记录注明内置图像工具从原创描述制作；二维运行帧来自本项目图集变形或本地渲染。没有把大肥鱼、AgentPaw 或 VRoid 的角色素材放入此快照，也没有将它们的素材改写为本项目版权。Noto Sans SC 保留 SIL OFL 文本，Qt/PySide 保留各自许可证。

此源码快照只包含已完成的二维运行图片，不包含历史 Blender 工程、未提交的设计试作或外部服务任务。旧制作资料在本机保留；第三方说明中提到的历史制作路径不能理解成公开仓库已附带这些文件。由用户导入或生成的角色属于用户自己的资料，公开源码不会携带当前用户的自定义角色包。

小猫与机器人静态 PNG 的 Blender `File` 文本字段仅保留原工程文件名，避免携带制作机的绝对路径；该操作只修改该文本块并更新其 CRC，不改变任何像素、IDAT 数据或其它元数据。图集中的 caBX/C2PA 来源凭证完整保留，界面文案整理不改变素材的生成来源。清单单独记录这两项元数据处理。

测试树不附带私有制作产物。依赖本机试作包、三维预览或旧美术制作目录的历史用例不纳入公开快照。其余用例使用隔离目录、替身接口或 Qt offscreen；实际客户端登录、真人麦克风、云端推理与用户桌面体验不能由这些测试代替。
