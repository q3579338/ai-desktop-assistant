# 回复朗读 · 1.23.0

本版已移除语音输入。气泡和聊天页没有录音按钮，设置没有识别语言或麦克风选项；程序不会启动录音或语音识别进程。

收到回复后，可点击聊天页的“朗读回复”。操作开始后可停止，结束或失败会给出明确状态。长错误说明可以完整阅读，状态卡不替换任务提示，也不抢焦点。

“设置 → 朗读”可选择 Windows 已安装的声音、语速和是否自动朗读。自动朗读默认关闭，只在聊天窗口和助手均显示时播放新回复。检测声音只枚举输出组件，不录音、不播放，不自动安装软件。

声音设置保存在助手自己的 voice-settings.json。旧配置里的声音、语速与自动朗读继续兼容；旧的识别语言字段不再使用。隐藏助手、关闭聊天、切换角色或退出会停止朗读。

朗读使用 Windows 自带 System.Speech 和默认声音输出设备，不调用语音云服务。只有明确开始播放并正常结束才显示完成；用户停止、设备错误与启动失败分别处理。

后台检查使用输出到空流的真实合成与替身界面，不进行有声播放；这些检查不代替用户对扬声器效果的试听。
