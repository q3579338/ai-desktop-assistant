# 小猫身后的小场景（1.16.0）

1.16.0实际使用紧凑组合模式：右键助手 → “小猫身后的小场景 / 小屋与树木…”，勾选显示并保存。房屋、树、花盆与灯画在宠物后方，保持原有助手窗口尺寸，随宠物一起拖动和缩放。取消显示恢复原宠物大小。原有每角色布局、装饰开关与旧位置数据保留；紧凑模式不使用独立桌面坐标，也不显示独立装饰窗口。背景不新增原有宠物窗口之外的点击区域，但原有宠物交互区域内仍响应点击。

以下为旧版独立装饰布局的兼容资料，默认界面已不再使用：

右键助手 → “桌面小天地 / 小屋与树木…”。勾选显示，分别选择小屋、小树、花盆和路灯，调整60%–160%大小，保存。

“编辑摆放”临时显示并解锁选中的装饰，可拖动每个物件。选择“保存并锁定”保留位置；“取消”恢复上次保存的布局和显隐。首次默认不显示。隐藏助手和显示装饰分别控制；收起全部装饰可取消“显示桌面小天地”并保存。退出助手时一并关闭。

日常装饰是无边框透明窗口，空白与图像区域均不接收点击；编辑期间物件矩形范围接收拖动。装饰不置顶，不抢键盘焦点，不持续播放动画，无定时刷新循环。窗口被工作应用盖住属于当前默认层级行为，尚不是Windows壁纸层嵌入。

布局本机保存到应用状态目录的 `desktop-world.json`，按角色分开；原子写入失败会显示错误，保留原布局。换角色只切换显示，不把一个角色的摆放复制给另一个，也不在切换时写文件。1.15 之前保存的全局布局只归首次运行新版本时正在使用的角色，等该角色下一次保存后才改写成按角色存放，其它角色仍从默认开始。显示器移除或可用区域变化时重新夹紧边界。

四种图形为本项目代码绘制的原创2D装饰。当前不包含宠物绕树、进屋、自动换装、图片生成家具或Three.js桌面宿主。现有Five-pair候选、Three.js试作和衣柜网页设计仍是各自独立的未完成工作。

后台测试分为offscreen逻辑/渲染和独立Windows桌面原生窗口样式验证。没有执行用户真实桌面上的点击穿透人工验收，不能将原生样式检查说成所有应用交互兼容已经证明。
